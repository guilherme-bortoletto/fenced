# Decision records

MADR cut down to the parts that get used. Title, status, date, context, decision, consequences.

A record is not rewritten to match a later opinion. It gets a new status and a successor.

The fifth fence reads this folder. A record with no status, with no date, or missing from the table
below fails the build, and so does a row below that points at a file that is not here.
